# RSA External Practical – Set B

**Subject:** Responsible and Safe AI Systems (AIML4001)

**University:** CHARUSAT University

**Enrollment Number:** 23CS059

## Project Title
Explaining Instant EMI-Finance Decisions at an Electronics Showroom

## Description
This practical implements an Explainable AI pipeline using the German Credit Dataset to explain credit decisions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- SHAP
- LIME
- Matplotlib

## Tasks Implemented
1. Dataset Loading and Preprocessing
2. Random Forest Classification
3. SHAP Global Feature Importance
4. SHAP Local Explanation
5. LIME Explanation and Comparison
6. Rejection Message and Fairness Check

## Model Results
- Accuracy: 77%
- ROC-AUC: 0.8113
- SHAP-LIME Agreement: 2/3
